# Hệ Thống Typography & Color Palette - Website Thần Số Học (Numerology)

Bảng thiết kế hệ thống màu sắc (Color Palette) và kiểu chữ (Typography) hiện đại, tinh tế, mang hơi hướng chiêm tinh học / khai sáng nhưng vẫn sạch sẽ, dịu mắt, chuẩn độ tương phản (WCAG AA/AAA) và không sử dụng theme tối hoàn toàn (Dark mode nặng nề).

---

## 1. Triết Lý Thiết Kế (Design Philosophy)

* **Phong cách:** Sang trọng, hiện đại, huyền bí nhẹ nhàng (Mystic Elegance) và đem lại cảm giác bình an, thông suốt.
* **Tông màu chủ đạo:** Kết hợp giữa màu vàng bơ dịu (**Butter / Soft Amber**) và màu xanh ngọc bích / lục bảo đậm (**Deep Emerald / Teal**) lấy cảm hứng từ bảng mẫu, pha thêm các gam màu trung tính nhẹ nhàng để tạo chiều sâu mà không gây chói mắt.
* **Nguyên tắc tương phản:** Đảm bảo độ dễ đọc (Legibility & Readability) tuyệt đối cho các bài viết luận giải dài đặc thù của ngành thần số học.

## 3. Hệ Thống Typography (Font System)

### 3.1. Lựa Chọn Phông Chữ (Font Pairing)

1. **Heading Font (Tiêu đề):** `Cinzel` hoặc `Playfair Display` / `Cormorant Garamond`
   * *Đặc tính:* Serif cao cấp, đường nét thanh lịch, rất đặc trưng cho các chủ đề chiêm tinh, triết học và thần số học.
2. **Body & UI Font (Nội dung & Giao diện):** `Plus Jakarta Sans` hoặc `Inter` / `Be Vietnam Pro`
   * *Đặc tính:* Sans-serif hiện đại, hình học cân đối, hỗ trợ tiếng Việt hoàn hảo, cực kỳ dễ đọc ở kích thước nhỏ.
3. **Number Display Font (Hiển thị các con số thần số học):** `Cinzel Decorative` hoặc `Bodoni Moda`
   * *Đặc tính:* Tạo điểm nhấn ấn tượng cho các con số định mệnh (1-9, 11, 22, 33).

## 4. Ứng Dụng Thực Tế Vào UI Component (CSS / Tailwind Tokens)

### 4.1. Khai Báo Biến CSS (CSS Variables)

```css
:root {
  /* Brand Colors */
  --color-primary: #013E37;
  --color-primary-light: #267D71;
  --color-accent-butter: #FFEFB3;
  --color-accent-amber: #F9E79F;
  --color-accent-mauve: #8C6A81;

  /* Neutral & Backgrounds */
  --bg-page: #FAF8F5;
  --bg-surface: #FFFFFF;
  --bg-subtle: #EEF5F3;
  --border-subtle: #E2E8E5;

  /* Typography Colors */
  --text-heading: #0D2B26;
  --text-body: #2D3E3A;
  --text-secondary: #5F736E;
  --text-muted: #93A39F;

  /* Font Families */
  --font-serif: 'Cinzel', 'Playfair Display', serif;
  --font-sans: 'Plus Jakarta Sans', 'Be Vietnam Pro', sans-serif;
}
```

## 5. Hướng Dẫn Phối Màu Cho Các Khối Giao Diện Cụ Thể

1. **Hero Section (Tra cứu Thần Số Học):**
   * *Background:* `#FAF8F5` kết hợp một quầng sáng mềm mại (radial blur) màu `#FFEFB3` ở góc.
   * *H1 Title:* `#013E37` với font `Cinzel`.
   * *Input nhập Ngày sinh / Họ tên:* Nền `#FFFFFF`, viền `#E2E8E5`, focus ring `#267D71`.
   * *Nút bấm "Tra Cứu Ngay":* Nền `#013E37`, chữ trắng `#FFFFFF`, hover chuyển sang `#267D71`.

2. **Card Con Số Chủ Đạo (Life Path Result Card):**
   * *Khung card:* Nền `#FFFFFF`, viền mỏng `#E2E8E5`, đổ bóng nhẹ `0 4px 20px rgba(1, 62, 55, 0.05)`.
   * *Huy hiệu con số (Number Badge):* Nền `#FFEFB3`, chữ số `#013E37` font lớn nổi bật.
   * *Nội dung luận giải:* Chữ `#2D3E3A` với `line-height: 1.65` tạo cảm giác thư thái khi đọc.

3. **Box Lời Khuyên / Ý Nghĩa Vũ Trụ (Insight Box):**
   * *Background:* `#EEF5F3` (xanh ngọc sương mờ).
   * *Viền trái (Border left):* `4px solid #267D71`.
   * *Chữ dẫn chứng:* `#8C6A81` dạng chữ nghiêng *Italic*.
